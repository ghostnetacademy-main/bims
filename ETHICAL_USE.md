# Ethical Use Notice

This repository contains **intentionally vulnerable software** built for
hands-on cybersecurity education (Red/Blue team Capture-The-Flag training).
It ships with planted weaknesses on purpose — default credentials, SQL
injection, unrestricted file upload (web shell), and an exposed config path.

## This software is for:
- Isolated lab ranges and classroom CTF exercises
- Learning offensive techniques and the defensive fixes that stop them
- Authorized training events where every participant has consented

## This software is NOT for:
- Deploying as, or alongside, any real information system
- Exposing to the public internet without strict isolation and egress
  controls (the file-upload bug is remote code execution by design)
- Attacking any system you do not own or lack written authorization to test

## Data
All residents, households, officials, businesses, blotter entries and
other records are **fictional**. Any resemblance to a real barangay,
person, or record is coincidental. Do not load real personal data into
this application.

## Legal
In the Philippines, unauthorized access to computer systems is penalized
under the **Cybercrime Prevention Act of 2012 (Republic Act No. 10175)**.
Run this only against targets you own or are authorized, in writing, to test.

By using this software you accept full responsibility for how you deploy it.
